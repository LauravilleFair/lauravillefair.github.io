# Lauraville Fair

Source for the [thelauravillefair.org](https://thelauravillefair.org) website, hosted on GitHub Pages.

Plain HTML/CSS — no build step. Edit the `.html` files directly.

- `RESOURCES.md` — domains, accounts, DNS, and open to-dos
- `assets/css/styles.css` — all styling (colors are at the top)
- `assets/js/main.js` — mobile menu, fair date (always the last Saturday in September), countdown

Anything highlighted in yellow on the draft site (`class="todo"`) still needs real content.

**After editing `styles.css` or `main.js`,** bump the `?v=` number on those links in every page, or visitors' browsers may keep using the old copy.
